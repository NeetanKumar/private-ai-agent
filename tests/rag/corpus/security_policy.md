# Information Security Policy

## Accounts
Passwords must be at least 14 characters long. Administrator passwords are rotated every 90 days. Production access requires a hardware security key for multi-factor authentication.

## Devices
All laptops must use full-disk encryption. A lost or stolen device must be reported to the security desk within 2 hours. USB mass storage is blocked by default and unblocked only with written approval.

## Networks
Employees must connect through the corporate VPN when using public Wi-Fi.

## Reporting
Suspected phishing emails are forwarded to the phishing mailbox and then deleted. Security incidents affecting customer data must be escalated to the security lead immediately.
